# Maintenance Notification
Welcome to the Maintenance Notification plugin! The purpose of this plugin is to give a blatantly obvious way to know when maintenance is scheduled.

## How does it work?
The way this plugin works is very simple. Whenever there is a notice in chat from Square Enix advising the player base of maintenance, there will be a large pop up window in your screen telling you that there is maintenance and will provide the entire message to provide you the date and time! It will flash and also play the danger bongos so you know it's there.

## Planned Features
So, as for right now, the plugins is pretty barebones with no config options. In the near future, I plan on implementing a couple options to toggle different features for the plugin. You will be able to toggle the flashing and the sound effect. I will come up with more features in time and will update this as needed, but the primary purpose of the function has already been achieved.
